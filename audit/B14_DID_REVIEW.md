## Численная и статистическая политика

Для конечных ATT и строго положительного конечного SE сохраняется обычное отношение ATT/SE. Нет абсолютного cutoff, округления малого ATT, clipping t или повышения diagnostic thresholds. Independent oracle проверяет положительные и отрицательные эффекты при масштабах от `1e-280` до `1e280`, subnormal inputs и overflow. Ненулевой `ATT=1e-300, SE=0` больше не получает p=1 через прежнюю tolerance `1e-16`.

При SE=0 studentization неопределена, включая точный 0/0: cell table хранит NaN t. Отрицательный/недоступный/nonfinite SE и nonfinite ATT также не превращаются в конечный статистический сигнал. Overflow отношения двух конечных inputs остаётся signed infinity в cell table; fitted pre check получает YELLOW и сохраняет infinite maximum. Любая undefined/nonfinite pre ячейка даёт caution, даже когда остальные ячейки проходят threshold. Общий `_finite_numeric`, ESS/SMD/clip checks и raw pre diagnostic policy не изменены.

Exact `ATT=0, SE=0` сохраняет legacy p-value convention 1. Это совместимость результата, а не подтверждение обычной normal approximation: fitted standardized diagnostic в этой ячейке остаётся undefined/YELLOW. Отрицательный/nonfinite SE и nonfinite numerator теперь дают NaN p-value; конечный положительный SE использует прежнюю normal-tail арифметику. Общая политика p-values, plotting, multiplier bootstrap и inference contracts не перерабатывалась.

OLS correction имеет узкий математический критерий: comparison responses должны быть **точно одинаковыми**, первая design column должна быть **точной единичной intercept для всех prediction rows**, а возвращённый `lstsq` rank должен быть полным. Тогда единственное решение — `(c, 0, …)`, и constant predictions сохраняются без SVD residue. Для nonconstant response, deficient rank, no/unit-scaled intercept и zero-column design прежнее least-squares решение сохраняется точно. Не вводятся epsilon, rank-policy changes или alternative extrapolation при deficient rank. Public caller всегда строит единичную intercept; width guard сохраняет также прежнюю private zero-column операцию.

При multiplier bootstrap и всех cell SE=0 simultaneous studentization также undefined. Новый узкий guard возвращает NaN critical value/bands без `nanmax/nanquantile` по all-NaN distribution. Bootstrap draws, RNG consumption и positive-SE branch не изменены. Partial-zero и прочие numerical bootstrap случаи сохраняют прежнюю политику; новый general simultaneous-band estimator не заявляется.
