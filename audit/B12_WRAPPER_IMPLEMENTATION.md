# B12 wrapper namespace implementation

Frozen baseline: `eb6dfe23f0a97991b6e3d6109febc1b0170e128d`. Bounded source scope: six DGP modules (shared helper, binary preperiod/base/functional, IV base/functional) and the new `tests/data/test_wrapper_namespace_contract.py`.

Enabled augmentation fields must have distinct nonempty literal string names. The shared ancillary helper rejects conflicts with all six fields before RNG or writes. Shared preperiod augmentation checks before the builder, after its callback, and before assignment; Tweedie has corresponding initial/final guards and its wrapper checks the prospective `_latent_A` oracle. RCT validates the combined enabled pre/ancillary namespace. Disabled pre options have no ordering or feature-selection role.

Successful binary/IV generation records immutable actual confounder names and fixed emitted roles, captured immediately before frame assembly. IV late callbacks cannot change conversion metadata by mutating instrument_name, include_oracle, or an aliased sampler-name list. These slotted dataclasses need two private `init=False`, `repr=False`, `compare=False` fields; public constructor signatures stay unchanged, while dataclasses.fields/asdict include the private state. Failed generation retains the previous successful snapshot. This metadata does not alter the raw DataFrame or generator arithmetic.

Wrappers order each actual role once. Automatic conversion retains actual numeric features, including disabled oracle-looking names; enabled oracles remain excluded. Existing explicit confounder selection is preserved. `user_id` is an identifier only when a wrapper actually adds one: a requested low-level numeric user_id is a feature, and an IV instrument called user_id remains an instrument when ancillary generation is off. Multi-treatment behavior is an unchanged reference, not an edited source path.

Compatibility is precise: valid correctly classified schemas preserve values, dtypes, labels/order and RNG. Previously misclassified disabled-oracle names intentionally participate in pre/ancillary X and conversion; this can change ancillary/pre values, RNG draws and contract feature lists. A blanket identical-output claim for these repaired schemas would be incorrect. Existing data-contract numeric, constant, finite, duplicate-value and statistical checks remain responsible for their own invariants.

Independent final test module: 162 cases, all passed; exact frozen baseline: 136 failed / 26 passed. Counts are parameterizations, not distinct bugs. Focused manifests preserve the actual precommit HEAD and source/test hashes; subsequent committed-byte linkage is recorded separately. Independent review and integration/CI evidence are completed in the audit checkpoint, without changing source bytes after freezing.

Separate confirmed residual: classic-RCT scenario conversion renames y to conversion after the underlying wrapper returns; pre_name='conversion' can therefore produce duplicate labels at that later boundary. This path is outside the six modules and remains a scoped follow-up. The prior numerical-zero DiD diagnostic failure, sensitivity, standalone Sphinx and release are separate work.
